# M.Tech Computer Engineering Study Hub & AI Tutor (2026 Pattern)

> **Autonomous NEP-2020 Compliant Curriculum Study Portal & AI Academic Companion**  
> **Institution**: Ajeenkya DY Patil School of Engineering, Department of Computer Engineering

---

## 🌟 Features Overview

- **Curriculum & Roadmap Explorer**:
  - Full semester navigation (**Semester I to IV**) mapped directly to the official NEP-2020 2026 Pattern syllabus.
  - Programme Core Courses (PCC):
    - `2604PCC501`: Advanced Algorithms (4 Credits)
    - `2604PCC502`: Advanced Database Systems (4 Credits)
    - `2604PCC503`: Machine Learning (4 Credits)
    - `2604PCC504`: Distributed Computing (4 Credits)
  - Programme Elective Courses (PEC - Elective I):
    - `2604OE505A`: Data Engineering (4 Credits)
    - `2604OE505B`: Business Intelligence (4 Credits)
    - `2604OE505C`: Internet of Things (4 Credits)
    - `2604OE505D`: Quantum Computing (4 Credits)
  - Practical & Skill Enhancement:
    - `2604PCC526`: Lab Practice - I (2 Credits: Algorithms, ADBMS, ML, Distributed Computing)
    - `2604VSEC506`: Introduction to Constitution of India (1 Credit)
  - Real-time Course Outcomes (CO1 to CO5) & Exam Scheme breakdown (TAE: 20, CAE: 20, ESE: 60 = 100 Marks).

- **Rich Study Materials & Revision Notes**:
  - Unit-by-unit comprehensive academic notes with mathematical recurrences, formulas, and time complexities.
  - Prescribed textbook mappings (CLRS, Korth, Bishop, Peter Flach, Kshemkalyani, Reis & Housley).
  - High-yield exam question banks (2 Marks, 5 Marks, 10 Marks).

- **Interactive Lab Practice Hub (Lab Practice - I)**:
  - Working reference code in Python, C++, SQL, and MongoDB.
  - Interactive browser simulations:
    - **0/1 Knapsack Solver**: Dynamic programming bottom-up table & optimal subset selection.
    - **Train Platform Scheduler**: Greedy earliest arrival/departure timeline visualizer.
    - **Two Generals Protocol**: Coordination over unreliable/lossy channels.
    - **Bully Leader Election**: Broadcast message simulation and coordinator election.
    - **SQL & MongoDB Playgrounds**: Multi-level constraint schemas, joins, and aggregation pipelines.

- **Intelligent AI Tutor (SyllabusBot)**:
  - Built-in **Neural Syllabus Engine** (works 100% offline with zero setup).
  - Optional support for **Google Gemini Live LLM** via custom API Key.
  - One-click prompt chips, code explanations, step-by-step mathematical derivations.

- **Student Productivity Tools**:
  - **Syllabus Progress Tracker**: Mark units as completed to track study percentage.
  - **Interactive Practice Quizzes**: Immediate scoring and celebration confetti.
  - **3D Flip Flashcards**: Memorize formulas, theorems, and key algorithms.
  - **Internal Mark & GPA Target Calculator**: Estimate required End-Sem (ESE) marks.
  - **Instant Search (`Ctrl + K`)**: Real-time filter across all subjects, topics, and lab assignments.
  - **Dark / Light Theme Toggle**: Sleek glassmorphism cyberpunk and academic themes.

## 🚀 How to Run Locally

### 1. Requirements
- Node.js (v18+) and npm installed.

### 2. Start the Dev Server
In your terminal (VS Code or Antigravity):
```bash
cd "e:\Study\ME CSE"
npm install
npm run dev
```

Open your browser at:
`http://localhost:5173/`

### 3. Build for Production
```bash
npm run build
```
The optimized bundle will be generated in `dist/`.
